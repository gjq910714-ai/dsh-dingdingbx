# 字段级填写规则

## 报销明细（每条）

| 字段 | 必填 | 怎么填 | 备注 |
|---|---|---|---|
| 报销金额（元） | ✅ | 价税合计（含税），只填数字 | `228.00` 会显示成 `228` |
| 费用发生日期 | ✅ | 开票日期 | 日历要悬停确认再点 |
| 费用类型 | ✅ | `报销 > 办公` | 二级菜单；差旅/餐饮/打车按实际 |
| 费用说明 | ✅ | 一句话 + 发票号码 + 开票日期 | 号码必须与票面逐位一致 |
| 发票 | — | 见 §添加发票 | 不用「添加附件」 |
| 附件 | — | 通常留空 | 发票已进「发票」栏，不必重复 |

## 添加发票 / 编辑发票

| 字段 | 必填 | 填法 |
|---|---|---|
| 发票类型 | ✅ | 见下方对照表 |
| 含税金额 | ✅ | 票面「价税合计（小写）」 |
| 不含税金额 | — | 票面「金额」合计 |
| 开票日期 | ✅ | 票面开票日期 |
| 发票代码 | ✅（红星） | 数电票填 `无` |
| 发票号码 | ✅ | 20 位号码原样抄 |
| 发票校验码 | 视模板 | 数电票填 `无`；老式票填后 6 位 |
| 购方税号 | — | 购买方纳税人识别号 |
| 销方税号 | — | 销售方纳税人识别号 |

### 发票类型对照

| 票面抬头 | 选 |
|---|---|
| 电子发票（普通发票） | 增值税电子普通发票 |
| 电子发票（增值税专用发票） | 增值税电子专用发票 |
| 增值税专用发票（纸质） | 增值税专用发票 |
| 增值税普通发票（纸质） | 增值税普通发票 |

### 数电票 vs 老票

- **数电票**：20 位发票号码；无发票代码、无校验码、无密码区。表单强制要求的代码/校验码填 `无`。
- **老式发票**：发票代码 10/12 位 + 发票号码 8 位 + 校验码后 6 位，全部照抄。

## 表尾

| 字段 | 必填 | 说明 |
|---|---|---|
| 归属人 | 自动 | 一般为当前登录人 |
| 归属部门 | 通常非必填 | 空着也行 |
| 所在部门 | ✅ | 必选；通讯录里属于多个部门时会出现选择框 |
| 企业主体 | 自动 | 跟随当前组织 |
| 付款时间 | 非必填 | 报销可以不填 |
| 关联申请单 | 非必填 | 有对应申请单时才选 |
| 备注 | 非必填 | |

## 校验规则

- `报销总额 = Σ 明细金额`，表头自动汇总，改动后要重新确认。
- 发票卡片金额 = 明细金额，否则财务会打回。
- 流程节点能生成 = 必填项齐全（流程区显示"必填信息填写后，流程将自动显示"）。
